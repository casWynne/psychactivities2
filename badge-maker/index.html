Help

Export your badge

Moodle accepts both formats. Maximum file size: 256 KB.

SVG —

  • Crisp at any size — never pixelated
  • Very small file size
  • Easy to edit later
  • Not previewed by some older software

JPG —

  • Opens everywhere, very compatible
  • Good for previews and documents
  • Fixed resolution — blurry if enlarged
  • No transparency (white background)
