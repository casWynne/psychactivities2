# Archive

Superseded and unlinked pages from earlier iterations of CCTK, kept for reference rather than deleted outright (old GitHub Pages URLs may still be shared externally, e.g. in Moodle).

Nothing in here is linked from the live site (`index.html`) or from any other active tool. Each item was replaced by a newer, self-contained folder at the repo root:

- `css/`, `js/`, `data/` — the original site-wide stylesheet/script/data folders used by the old `tasks/*.html` pages below, before each tool moved to its own self-contained folder.
- `tasks/qsort/` — superseded by [`q-sort/`](../q-sort/).
- `tasks/mop2627 v1/`, `tasks/mop2627 v2/` — draft iterations superseded by [`mop2/`](../mop2/).
- `tasks/mop.html` — superseded by [`mop/`](../mop/).
- `tasks/audio_illusions.html`, `dot_probe.html`, `drag_task.html`, `flanker.html`, `lavvaan.html`, `morpheme_madness.html`, `stimuliShuffle.html`, `visual_illusions.html`, `wsct_task.html` — old standalone cognitive task demos, no longer part of the site.

Some very old pages (e.g. `tasks/mop.html`) reference `../assets/...` — those images won't resolve here since `assets/` stays live at the repo root and wasn't duplicated into this folder.
